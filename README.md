# GeoCaching

Android-приложение для поиска точки на карте по GPS-координатам.

## Что делает программа

Приложение определяет текущее местоположение пользователя, показывает карту и помогает найти заданную точку по расстоянию и направлению движения.

Когда пользователь приближается к цели, приложение сообщает о нахождении точки.

## Основные возможности

- Определение текущего местоположения
- Отображение карты
- Показ точки назначения
- Расчёт расстояния до цели
- Определение направления движения
- Обновление координат в реальном времени
- Сообщение о нахождении точки

## Используемые технологии

- Kotlin
- Android Studio
- Yandex MapKit SDK
- Google Play Services Location
- FusedLocationProviderClient

## Как запустить

1. Открыть проект в Android Studio
2. Запустить приложение на телефоне или эмуляторе
3. Разрешить доступ к геолокации
4. Следовать по карте к заданной точке

## Примечание

Для корректной работы приложению нужен доступ к геолокации и интернету.
